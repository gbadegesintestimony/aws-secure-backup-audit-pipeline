# Screenshots and privacy

This folder contains selected historical assessment screenshots, organized by topic. AWS console account headers were obscured and a policy ARN area was masked for public sharing. These changes should not affect the core technical evidence.

**Before publishing publicly:** inspect every image at full resolution. Confirm that no account IDs, identifiers, email addresses, public IPs, API keys, access tokens, private keys or unrelated resources are exposed. Additional masking may be necessary. If unsure, omit the screenshot.

These images reflect a lab whose resources were deleted after assessment verification. See [evidence index](../docs/EVIDENCE_INDEX.md).
